Do NOT interpret incomplete match point samples as season rankings. Unknown fields must be null, never made-up 0. Reconcile player identities before aggregation of transfers. True attack% is total kills / total attempts, not average of percent per match.

Before automatic ingestion, check website terms, permissions and possible licensed feeds. Do not bypass access restrictions.
