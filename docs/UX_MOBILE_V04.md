# VolleyAtlas v0.4 — Mobile UI

Independent light, editorial visual identity; iOS-inspired floating translucent tab bar, soft segmented controls, large tappable match cards.

Inspiration: matchday grouping and set-by-set results from InSystem Volley, but no code or visual assets have been copied.

Features:
- Matchday / round groups and compact list modes
- Search and league/round filters
- Save match bookmarks locally; no account required
- Mobile bottom tab bar with safe-area insets (5 tabs)
- Match and player details as swipe-style sheets (close via Back or Escape)
- Scoreboard by set, partial player scoring for selected matches
- Player comparison clearly limited to sample
- Gender toggle, with empty state for women's data until verified games are loaded
- User-facing action "Otvori zapisnik" rather than prominent source labels
- Original provenance retained in raw snapshot

Future: full official box score ingest, actual league standings, women data.
